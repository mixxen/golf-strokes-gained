Comparison baseline

PGA TOUR — Broadie 2003–2010

Historical · unadjusted

Every stroke is compared with the expected number of strokes a PGA TOUR player needed to hole out from the same lie and distance in Mark Broadie’s published ShotLink benchmark.

SG = J(start lie, distance) − 1 − J(finish lie, distance)
Method, lie mapping, and references

Off-green values come from Broadie’s Table B.1, estimated from more than eight million PGA TOUR ShotLink strokes from 2003–2010. Putting values use Broadie’s published PGA TOUR putting table.

Lie mapping: fairway and greenside bunkers use the sand curve. Deep rough with a direct route uses rough. Use Trees / recovery only when the direct route is obstructed. Fringe currently uses the fairway curve because the public benchmark has no separate fringe condition.

Distance handling: values are linearly interpolated between published points. Distances outside the published range use the nearest endpoint rather than undocumented extrapolation; the detailed methodology documents this limitation.

Scope: these are historical, unadjusted shot values. They do not reproduce the current official PGA TOUR statistic’s event, course, round, or field adjustment.
